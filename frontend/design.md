# Premium, Human-Designed Website Guidelines

Use these attributes when implementing the website:

## Visual Design

- Strong, distinctive visual identity
- Avoid generic SaaS/AI aesthetics
- Avoid excessive gradients
- Avoid excessive glassmorphism
- Avoid the typical purple/blue AI color palette
- Use a restrained, intentional color palette
- Use one strong accent color
- Prefer warm/off-white backgrounds where appropriate
- Use subtle borders instead of heavy shadows
- Use soft, realistic shadows
- Maintain consistent border-radius values
- Prioritize negative space
- Make the interface feel editorial and thoughtfully art-directed

## Typography

- Use a distinctive font pairing
- Strong typography hierarchy
- Large, confident headlines
- Tight line-height for headings
- Comfortable line-height for body text
- Carefully control text width
- Use font weight intentionally
- Avoid making every element bold
- Use typography rather than excessive containers to create hierarchy

## Layout

- Use a consistent grid system
- Maintain a coherent spacing scale
- Strong alignment throughout the page
- Introduce asymmetry where it improves composition
- Use intentional whitespace
- Create different visual rhythms between sections
- Avoid repetitive layouts
- Avoid excessive 3-column card grids
- Avoid putting every piece of content inside rounded cards
- Avoid excessive centered layouts
- Make important sections visually distinctive

## UI Design

- Clear primary/secondary/tertiary button hierarchy
- Refined hover states
- Thoughtful focus states
- Consistent icon sizes
- Consistent icon stroke weights
- Well-designed form fields
- Clear disabled states
- Clear error states
- Elegant empty states
- Subtle dividers
- Useful tooltips only when necessary
- Avoid unnecessary UI decoration

## Micro-interactions

- Add subtle hover feedback
- Use smooth transitions
- Use small scale/opacity changes where appropriate
- Make dropdowns and modals feel natural
- Add polished loading states
- Use skeleton loaders where appropriate
- Make interactions feel responsive and immediate
- Support keyboard navigation
- Respect reduced-motion preferences

## Animation

- Keep animation restrained and purposeful
- Prefer 150–300ms transitions for UI interactions
- Use subtle entrance animations
- Avoid animating everything
- Avoid excessive parallax
- Avoid bouncing or gimmicky animations
- Avoid constant floating elements
- Avoid animation that exists purely for decoration
- Use motion to communicate hierarchy and state changes

## Content

- Write concise, specific, human-sounding copy
- Avoid generic AI phrases
- Avoid excessive marketing buzzwords
- Avoid phrases like "revolutionize", "unlock your potential", "next-generation", etc.
- Use concrete language
- Keep headings short and confident
- Make the copy feel written specifically for this product
- Use realistic examples and meaningful labels
- Avoid filler text

## Images & Graphics

- Use imagery that supports the product's identity
- Avoid generic stock-photo aesthetics
- Prefer high-quality editorial imagery or purposeful illustrations
- Maintain a consistent visual language
- Avoid random decorative blobs
- Avoid unnecessary 3D illustrations
- Avoid adding graphics simply to fill empty space

## Cards & Containers

- Use cards only when they improve information hierarchy
- Avoid putting every section inside a card
- Avoid excessive rounded rectangles
- Use different visual treatments for different content types
- Keep card styling subtle and refined
- Give important content more visual prominence

## Responsive Design

- Design mobile layouts intentionally rather than simply shrinking desktop
- Reconsider layouts at each breakpoint
- Maintain typography hierarchy on smaller screens
- Preserve adequate whitespace
- Make touch targets comfortable
- Avoid horizontal overflow
- Ensure navigation feels natural on mobile

## Accessibility

- Maintain strong color contrast
- Use semantic HTML
- Support keyboard navigation
- Provide visible focus states
- Use meaningful labels
- Include appropriate ARIA attributes
- Support reduced motion
- Ensure the interface works with screen readers

## Code Quality

- Use clean, maintainable component architecture
- Avoid unnecessary dependencies
- Create reusable components where appropriate
- Keep styling consistent
- Use design tokens for colors, spacing, typography, and radii
- Avoid duplicated code
- Keep components logically separated
- Optimize images and assets
- Avoid unnecessary JavaScript
- Prioritize performance

## Avoid "AI-Generated" Patterns

Do NOT make the website look like a generic AI-generated template.

Avoid:

- Purple/blue gradient backgrounds
- Excessive glassmorphism
- Huge centered hero sections
- Excessive pill-shaped buttons
- Excessive rounded cards
- Repetitive card grids
- Random floating gradient blobs
- Generic dashboard layouts
- Excessive shadows
- Too many badges
- Excessive icons
- Unnecessary animations
- Generic stock illustrations
- Overly verbose marketing copy
- "AI startup" visual clichés
- Making every section visually identical

## Overall Design Principle

The final website should feel:

- Premium
- Intentional
- Human-designed
- Confident
- Sophisticated
- Minimal but not empty
- Visually distinctive
- Functional
- Fast
- Accessible
- Polished

Every visual element should have a reason to exist.

Prefer **fewer, better-designed elements** over adding more decoration.

The goal is not to make the website look "fancy." The goal is to make it feel like a **high-quality product designed by an experienced product/design team**.
